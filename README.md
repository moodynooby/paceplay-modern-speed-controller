# PacePlay: Modern Video Speed Controller

Speed up, slow down, advance and rewind HTML5 audio/video with shortcuts. Now with a modern UI.

## Links

- [GitHub Repository](https://github.com/moodynooby/paceplay-modern-speed-controller)
- [Firefox Addons](https://addons.mozilla.org/en-US/firefox/addon/paceplay-modern-controller/)

## Features

- Speed up playback
- Slow down playback
- Advance video
- Rewind video
- Keyboard shortcuts for all functions
- Modern, user-friendly interface

## Setup

1.  Clone the repository:
    ```sh
    git clone https://github.com/moodynooby/paceplay-modern-speed-controller.git
    ```

2.  Open your Chrome-based browser and navigate to `chrome://extensions`.
3.  Enable "Developer mode" in the top-right corner.
4.  Click "Load unpacked" and select the cloned repository's directory.
OR
2.  Open Firefox and navigate to `about:debugging#/runtime/this-firefox`.
3.  Click "Load Temporary Add-on..." and select any file inside the extracted folder (e.g., `manifest.json`).
